# docker-two-tier-application
# IT Support Ticket Management System

A two-tier web application built using Flask and MySQL,
containerized using Docker.

## Technologies
- Python and Flask
- MySQL 8.4
- Docker
- Docker Networking
- Docker Volumes
- phpMyAdmin

## Features
- Create support tickets
- View all tickets
- Set ticket priority
- Update ticket status
- Delete tickets
- Persistent database storage
- Database health endpoint

## Architecture

1. Flask application container
2. MySQL database container
3. phpMyAdmin management container

## Learning Objectives

- Build Docker images
- Run multiple containers
- Create custom Docker networks
- Configure environment variables
- Persist database data using Docker volumes
- Understand container-to-container communication
